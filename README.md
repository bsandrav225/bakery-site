# Пекарня «Домашний хлеб»

Сайт семейной пекарни: витрина, корзина, заявки и панель управления.

Стек: PHP 8, MySQL, Apache. Локально открывается через XAMPP, на хостинге — из корня домена или из подпапки.

## Запуск в XAMPP

1. Скопируйте проект в `C:\xampp\htdocs\d1`.
2. Запустите Apache и MySQL.
3. В phpMyAdmin создайте базу `bakery` и импортируйте `database/bakery.sql`.
4. Откройте http://localhost/d1/

Админка: http://localhost/d1/admin/  
Логин `admin`, пароль `admin123`. После установки лучше сразу сменить пароль.

Если сайт лежит не в папке `d1`, ничего править не нужно: адрес считается сам. Свои данные БД можно прописать в `admin/config.local.php` — образец лежит в `admin/config.example.php`.

## Что внутри

- Каталог с категориями и корзиной
- Форма заказа с записью в базу
- Статьи, акции, отзывы, фото работ
- Админка для всего этого содержимого

## Выкладка на хостинг

GitHub Pages этот проект не откроет: нужен обычный хостинг с PHP и MySQL.

Залейте файлы на сервер, создайте базу, импортируйте дамп, при необходимости скопируйте `admin/config.example.php` в `admin/config.local.php` и укажите доступ к MySQL. Папку `uploads` оставьте доступной для записи.
